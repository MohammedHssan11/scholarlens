# Evidence Traceability

**Owner:** Mariam Eladawy (Knowledge & Tooling Engineer)

## Purpose

This document describes how every answer generated by ScholarLens can be traced back to an approved research source.

---

## Evidence Flow

User Question

↓

Evaluation Case

↓

Approved Source ID

↓

Evidence Snippet

↓

Generated Answer

---

## Traceability Rules

1. Every supported answer must reference one or more approved `source_id` values.
2. Every source must exist in the approved source register.
3. Every factual claim must be supported by an evidence snippet from the original paper.
4. If supporting evidence cannot be found, the system must return **Evidence Not Found**.
5. The system must never use knowledge outside the approved corpus.

---

## Example

| User Question | Source | Reason |
|--------------|--------|--------|
| What is Agentic RAG? | paper-001 | Primary survey describing Agentic RAG concepts and architecture. |
| How does GraphRAG support Agentic RAG? | paper-007, paper-010 | Graph-based retrieval methods and GraphRAG implementation. |
| What research gaps exist? | paper-004 | Systematic review discussing current limitations and future work. |

---

## Validation

The current evaluation suite references only approved papers.

Unsupported, malformed, and prompt injection requests intentionally bypass evidence retrieval and return safe responses.
