# Approved paper corpus

**Owner:** Mariam Eladawy (Knowledge & Tooling Engineer)

Put the **8–15 approved papers** for the chosen narrow topic here.

## ⚠️ This repository is public

Do **not** commit paper PDFs unless you are certain the licence allows redistribution.
The PDF files in this folder are git-ignored on purpose.

What we commit instead: the **metadata** in `docs/source-register.md` — title, author,
year, DOI/URL, access date and licence note. That is what makes a citation traceable.
